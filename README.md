# Goldwater cuckold

Игровой мир для **Foundry Virtual Tabletop V12** по системе **World of Darkness**: Нью-Йорк,
Камарилья, Анархи, Шабаш, ночные клубы, особняки и подземки.

В релизе **2.0.0** — готовый мир со всеми **66 сценами** локальной Foundry: стены, двери, свет,
токены, заметки, сетка и фоны сохранены как есть. Мир ставится одной ссылкой, обязательные модули
Foundry предлагает доустановить сразу в процессе установки.

## Требования

| Компонент | Версия | Обязателен |
|---|---|---|
| Foundry VTT | 12.331 | да |
| Система World of Darkness (`worldofdarkness`) | 4.2.12 | да |
| Модуль Goldwater Assets (`goldwater-assets`) | 1.0.0 (1,12 ГБ) | да |
| Модуль FXMaster (`fxmaster`) | **5.0.1** | да (снег и облака) |
| Monk's Enhanced Journal (`monks-enhanced-journal`) | 12.02 | рекомендуется |
| Наборы Tom Cartos Modern (18 модулей) | по вашей покупке | нет, см. ниже |

## Установка

1. Установите систему **World of Darkness** 4.2.12: Setup → Game Systems → Install System.
2. Setup → **Game Worlds** → **Install World** → Manifest URL:

   ```
   https://github.com/HedgehogInTheGasMask/new-york-by-night-Foundry-world/releases/latest/download/world.json
   ```

3. Сразу после установки Foundry открывает окно **Install Package Dependencies**:

   - `goldwater-assets` 1.0.0 — обязательно, ~1,12 ГБ;
   - `fxmaster` 5.0.1 — обязательно, 19 МБ;
   - `monks-enhanced-journal` — необязательно.

   Нажмите **Install selected dependencies automatically** — Foundry скачает и поставит их сама.
   Если окно закрыть, мир останется в списке, но будет недоступен (MISSING_DEPENDENCY), пока модули
   не установлены: это штатное поведение Foundry, а не ошибка сборки.

4. Запустите мир. Модули включаются автоматически: конфигурация модулей уже записана в мире.

### Снег и облака (FXMaster 5.0.1)

Сцена **New York** `Uicwxtf2pNEmjfaS` рисует снег и облака модулем **FXMaster 5.0.1**. Версии 7.x
и 8.x считают тот же эффект другим кодом (в 8.3.0 снег переписан на шейдер, `density` нормализован
с 7.2.0), поэтому при тех же параметрах сцены картинка получается другой. Манифест модуля:

```
https://github.com/HedgehogInTheGasMask/new-york-by-night-Foundry-world/releases/latest/download/fxmaster.json
```

Это ссылка на неизменённый официальный архив v5.0.1. Эталонные параметры, проверка и откат —
[docs/FXMASTER-SNOW.md](docs/FXMASTER-SNOW.md). Мир требует ровно `5.0.1` (`minimum` и `maximum`):
с другой версией Foundry отметит мир как несовместимый, чтобы снег не «поехал».

## Tom Cartos

В локальной Foundry установлены 19 наборов **Tom Cartos Modern**. Их карты — платный контент,
условия автора запрещают распространение, поэтому **в релиз они не входят**; в мире остаются все
данные сцен, а без установленного набора сцена открывается без фона.

Все 19 наборов (18 используемых сценами и неиспользуемый Nakatomi Plaza) объявлены в
`relationships.recommends` мира: при установке мира Foundry показывает их в том же окне
зависимостей как «need to be manually installed». Автоматически они не ставятся — это ограничение
Foundry и лицензии, а не сборки. Установленный набор включается сам: мир уже содержит его id в
`core.moduleConfiguration`; отключить и удалить его можно штатно в Manage Modules и Setup.

Как поставить свои приобретённые наборы, как собрать из них отдельные приватные модули и что именно
нельзя публиковать — [docs/TOM-CARTOS.md](docs/TOM-CARTOS.md).

Ассеты модуля: портреты, токены, собственные карты, изображения журналов, музыка, видео.
Структура повторяет исходную, файлы не пережимались.

## Известные ограничения

- Три дорожки плейлистов (`Maenad Veyl — Out of Sight`, `Maenad Veyl — Unhealed`,
  `Knights & Bishops`) ссылаются на файлы, которых нет в исходной папке мира. Ссылки оставлены как
  есть, заглушки не создавались.
- Две иконки Monk's Enhanced Journal (`assets/text.png`, `assets/video.png`) отсутствуют в самом
  модуле версии 12.02 — это его внутренние файлы, к миру они не относятся.
- Девять изображений в журналах — внешние ссылки (imgur, tenor, reddit, userapi, ko-fi); без
  интернета они не загрузятся.
- Foundry 12 не устанавливает зависимости полностью молча: она показывает окно и ставит их по
  нажатию. Платные наборы Tom Cartos она не может поставить в принципе.

## Обновление

Manifest URL не меняется. Setup → **Update** у мира и у модулей. Порядок не важен.

## Права

Права на исходные изображения, музыку и карты принадлежат их авторам. В релиз входит только то, что
относилось к этому миру; материалы сторонних коммерческих модулей (Tom Cartos Modern) в него не
включены и не могут быть включены по условиям автора.
