# Goldwater cuckold

Игровой мир для **Foundry Virtual Tabletop V12** по системе **World of Darkness**: Нью-Йорк,
Камарилья, Анархи, Шабаш, ночные клубы, особняки и подземки.

В релизе **3.1.0** — мир с **12 сценами**, полностью самодостаточный: все фоны, портреты и токены
лежат внутри архива мира и модуля ассетов. Токены персонажей заменены на библиотеку
**New York by Night**, а прежние портреты персонажей и альтернативные версии подключены через
**Token Variant Art**. Снег удалён со всех сцен, облака и туман сохранены.

## Требования

| Компонент | Версия | Обязателен |
|---|---|---|
| Foundry VTT | 12.331 | да |
| Система World of Darkness (`worldofdarkness`) | 4.2.12 | да |
| Модуль Goldwater Assets (`goldwater-assets`) | 1.0.0 (1,12 ГБ) | да |
| Модуль FXMaster (`fxmaster`) | **5.0.1** | да (облака и туман) |
| Token Variant Art (`token-variants`) | 5.1.6 | да (варианты токенов) |
| Monk's Enhanced Journal (`monks-enhanced-journal`) | 12.02 | рекомендуется |

Наборы **Tom Cartos Modern** больше не нужны: сцены, которые их использовали, из мира удалены.

## Установка

1. Установите систему **World of Darkness** 4.2.12: Setup → Game Systems → Install System.
2. Setup → **Game Worlds** → **Install World** → Manifest URL:

   ```
   https://github.com/HedgehogInTheGasMask/new-york-by-night-Foundry-world/releases/latest/download/world.json
   ```

3. Foundry откроет окно **Install Package Dependencies**:

   - `goldwater-assets` 1.0.0 — обязательно, ~1,12 ГБ;
   - `fxmaster` 5.0.1 — обязательно, 19 МБ;
   - `token-variants` 5.1.6 — обязательно (сам подтянет `lib-wrapper`);
   - `monks-enhanced-journal` — необязательно.

   Нажмите **Install selected dependencies automatically**. Если окно закрыть, мир останется в
   списке, но будет недоступен (MISSING_DEPENDENCY), пока модули не установлены.

4. Запустите мир. Модули включаются автоматически: конфигурация модулей уже записана в мире.

## Сцены

В мире осталось 12 сцен — те, чьи фоны можно законно распространять и которые действительно
находятся внутри сборки:

| Показатель | Значение |
|---|---:|
| Сцен | 12 |
| Стены | 869 |
| Двери (в т.ч. секретные) | 223 (91) |
| Источники света | 589 |
| Токены на сценах | 18 |
| Заметки | 62 |
| Тайлы | 17 |

Сохранены: `New York` (карта и видео-версия), `New York 2`, `New York (old)`, `Манхатан`,
`Манхатан (Copy)`, `Title Screen`, `Vegas`, `capella` и три этажа «Заброшенного особняка».
Полная таблица — [docs/SCENES.md](docs/SCENES.md), история удаления — в отчёте релиза.

Удалены 53 сцены на картах Tom Cartos (платный контент, лицензия запрещает распространение, а без
купленного набора фон отсутствует) и пустая сцена `void` без фона. Вместе со сценами удалены их
стены, двери, свет, тайлы и заметки — данных, которые ссылались бы на отсутствующие файлы, не осталось.

## Токены и Token Variant Art

183 Actor Documents, у 175 заменён основной токен, у 80 настроены альтернативные варианты.
Основной токен — нейтральный вариант без оружия (`_noitems` / `_noweapon`), если он есть в библиотеке.

Варианты записаны штатным для Token Variant Art 5.1.6 способом — флагом актора
`flags.token-variants.variants` со списком `{imgSrc, names}`; кнопка вариантов на Token HUD
показывает их и переключает изображение. Полная таблица сопоставления —
[docs/TOKENS.md](docs/TOKENS.md).

Игровые данные не менялись: имена, биографии, характеристики, предметы, эффекты, папки, права
доступа и настройки токенов, не связанные с картинкой, остались прежними. Ни один Actor Document
не удалён и не создан заново.

## FXMaster и снег

Снег удалён со всех сцен: эффект `core_snowstorm` убран из `New York` и `New York 2`, погодный
пресет `blizzard` снят с `Манхатан (Copy)`. Облака `core_clouds` на обеих сценах New York и туман
на `Title Screen` / `Манхатан` сохранены.

Мир требует ровно FXMaster **5.0.1** (`minimum` и `maximum`): это версия, проверенная на Foundry
12.331, более новые ветки считают те же эффекты другим кодом. Манифест модуля — неизменённый
официальный архив:

```
https://github.com/HedgehogInTheGasMask/new-york-by-night-Foundry-world/releases/latest/download/fxmaster.json
```

## Tom Cartos

Платные наборы **Tom Cartos Modern** в релиз не входят и больше не объявляются зависимостями мира.
Если вы купили их сами, карты можно использовать в своей игре — как собрать из них отдельные
приватные модули, описано в [docs/TOM-CARTOS.md](docs/TOM-CARTOS.md). Сцены на этих картах из
публичной сборки удалены, потому что без покупки они открывались бы пустыми.

## Известные ограничения

- Две иконки Monk's Enhanced Journal (`assets/text.png`, `assets/video.png`) отсутствуют в самом
  модуле версии 12.02 — это его внутренние файлы, к миру они не относятся.
- Девять изображений в журналах — внешние ссылки (imgur, tenor, reddit, userapi, ko-fi); без
  интернета они не загрузятся.
- Foundry 12 не устанавливает зависимости полностью молча: она показывает окно и ставит их по
  нажатию.

## Обновление

Manifest URL не меняется. Setup → **Update** у мира и у модулей. Порядок не важен. При обновлении
с 2.0.0 мир сам уберёт удалённые сцены — ничего вручную чистить не нужно.

## Права

Права на исходные изображения, музыку и карты принадлежат их авторам. В релиз входит только то, что
относилось к этому миру; материалы сторонних коммерческих модулей (Tom Cartos Modern) в него не
включены и не могут быть включены по условиям автора.
