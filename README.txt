
# Goldwater cuckold

Игровой мир для **Foundry Virtual Tabletop V12** на системе **World of Darkness**.

## Установка

1. Установите систему **World of Darkness** (`worldofdarkness`), версия `4.2.12`.
2. Откройте Foundry VTT → Setup → Game Worlds.
3. Нажмите **Install World**.
4. Вставьте Manifest URL:

   `https://github.com/HedgehogInTheGasMask/new-york-by-night-Foundry-world/releases/latest/download/world.json`

5. Нажмите **Install**.

## Содержимое

- Игровые сцены и карты.
- Персонажи и игровые сущности.
- Предметы, дисциплины, оружие и броня.
- Компендиумы.
- Изображения и игровые ресурсы.
