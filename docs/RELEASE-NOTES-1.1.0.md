# Goldwater cuckold 1.1.0 + Goldwater Assets 1.0.0

## Что изменилось

Вся графика и медиа, на которые ссылаются документы мира, вынесены в отдельный модуль
`goldwater-assets`. В мире остались данные и небольшая резервная копия исходной папки `assets/`
(81 файл, около 29,6 МиБ) — она оставлена намеренно как страховка для старых макросов и прямых
путей.

### Мир Goldwater cuckold 1.1.0

- Ссылки в актёрах, предметах, сценах, журналах, плейлистах, настройках и четырёх компендиумах
  переписаны на `modules/goldwater-assets/...` — 435 значений, 678 ссылок.
- В манифест добавлена обязательная зависимость `goldwater-assets` 1.0.0; зависимость от системы
  `worldofdarkness` 4.2.12 сохранена.
- `monks-enhanced-journal` добавлен как рекомендация (`relationships.recommends`) — он нужен только
  для иконок страниц журналов и не блокирует запуск.
- Игровые данные не менялись: 25 999 записей LevelDB до и после, те же ключи, все документы
  разбираются, а после обратной замены новых путей на старые каждый документ совпадает с исходным
  байт-в-байт.

### Модуль Goldwater Assets 1.0.0

- 347 файлов, 1 070 МиБ: 50 музыкальных файлов, 10 карт и фонов, 5 видео, 47 изображений журналов,
  110 портретов, 60 токенов, 21 превью сцен, 43 прочих изображения, 1 PDF.
- Файлы не пережимались и не переименовывались; структура папок повторяет исходную.
- Неиспользуемых файлов и конфликтов имён нет.

## Установка и обновление

1. Система World of Darkness 4.2.12.
2. Модуль: Setup → Add-on Modules → Install Module →
   `https://github.com/HedgehogInTheGasMask/new-york-by-night-Foundry-world/releases/latest/download/module.json`
3. Мир: Setup → Install World / Update →
   `https://github.com/HedgehogInTheGasMask/new-york-by-night-Foundry-world/releases/latest/download/world.json`
4. Включите Goldwater Assets в настройках мира (Settings → Manage Modules).

При обновлении мир и модуль скачиваются заново; модуль весит около 1,12 ГБ (1070 МиБ),
поэтому обновление займёт время и место на диске.

## Сторонние модули

18 модулей Tom Cartos Modern используются 122 файлами карт. Они **не входят** в релиз: это платные
материалы, распространяемые автором по подписке <https://www.patreon.com/tcmodern>. Без них
соответствующие сцены откроются без фона, остальные данные не пострадают. Полная таблица — какие
сцены зависят от какого модуля и где взять manifest — в
[docs/ASSETS-REPORT.md](ASSETS-REPORT.md), раздел 6.

## Известные ограничения

- Три дорожки плейлистов (`Maenad Veyl — Out of Sight`, `Maenad Veyl — Unhealed`,
  `Knights & Bishops`) ссылаются на файлы, которых нет в исходных папках мира; ссылки не
  подменялись.
- Две иконки Monk's Enhanced Journal (`assets/text.png`, `assets/video.png`) отсутствуют в версии
  12.02 самого модуля — это его внутренние файлы.
- Девять изображений в журналах — внешние ссылки (imgur, tenor, reddit, userapi, ko-fi) и требуют
  интернета.

## Проверки

Перед выпуском: полный аудит 18 LevelDB-коллекций, round-trip проверка всех изменённых документов,
сверка регистра имён, проверка структуры обоих архивов и имитация чистой установки в пустом `Data`
с проверкой CRC — без расхождений. Подробности и воспроизводимые команды — в
[docs/ASSETS-REPORT.md](ASSETS-REPORT.md).
