# Goldwater cuckold 2.0.0

Релиз 2.0.0 — первый релиз, где мир объявляет свои зависимости сам и переносит **все** сцены
локальной Foundry вместе с их содержимым.

## Состав

| Пакет | Версия | Файлы |
|---|---|---|
| Goldwater cuckold (мир) | **2.0.0** | `world.json`, `world.zip` (152 МиБ) |
| Goldwater Assets (модуль) | 1.0.0 | `module.json`, `goldwater-assets.zip` (1,12 ГБ) |
| FXMaster | 5.0.1 | `fxmaster.json`, `fxmaster-5.0.1.zip` (19 МБ) |

Ассеты и FXMaster не менялись с 1.1.0 — те же байты, те же sha256.

## Что нового

- **66 сцен** — весь список локальной Foundry, включая Tom Cartos, «Манхатан», «Vegas», особняк,
  подземку, тюрьму, парковку, библиотеку и т. д. Стены, двери, свет, токены, заметки, звуки, тайлы,
  сетка и фоны сохранены; сравнение с источником по каждой сцене — без расхождений.
- `relationships.requires`: `goldwater-assets` 1.0.0 и `fxmaster` ровно 5.0.1 с manifest URL.
  Foundry показывает окно **Install Package Dependencies** и ставит их одним нажатием.
- `relationships.recommends`: Monk's Enhanced Journal 12.02 (закреплён на версии для Foundry 12) и
  18 наборов Tom Cartos Modern. Платные наборы Foundry перечисляет как «need to be manually
  installed» — они не распространяются (см. `docs/TOM-CARTOS.md`).
- `core.moduleConfiguration` в мире включает `goldwater-assets`, `fxmaster`,
  `monks-enhanced-journal` и все наборы Tom Cartos: после установки модулей они активны сразу.
- Снег и облака на сцене New York `Uicwxtf2pNEmjfaS` — эталонные: `0.3/90/0.5/5/0.8/1` и
  `1.2/90/0.6/5/0.099/1`, `tint.apply false`. Проверяется сборкой и проверкой архива.

## Обновление с 1.1.0

Manifest URL не меняется. Setup → Update у мира. Мир обновится до 2.0.0; модуль ассетов остаётся
1.0.0, FXMaster — 5.0.1. Данные сцен не перезаписываются вручную: архив содержит те же сцены с теми
же id.

## Проверка на чистой установке

Отдельный экземпляр Foundry 12.331 build 331 (свой `--dataPath`, порт 30123, копия лицензии),
система World of Darkness 4.2.12, пустой каталог модулей. Живая Foundry не затрагивалась.

- Мир установлен по `world.json` из локального зеркала релиза.
- Foundry открыла **Install Package Dependencies**: 3 автоматические зависимости, 19 Tom Cartos —
  «need to be manually installed». После нажатия «Install selected dependencies automatically»
  `goldwater-assets` и `fxmaster` установились сами, мир получил статус **VERIFIED**.
- Мир запустился без ошибок: **66 сцен**, 18 026 стен, 1 253 двери (+102 секретные), 2 682 света,
  70 токенов, 42 тайла, 62 заметки, 3 звука — совпадает с локальным источником.
- Из 159 проверенных путей к ресурсам отсутствуют только 78 — все внутри 18 наборов Tom Cartos
  (их нет в публичном релизе по лицензии). Ни одного битого пути вне Tom Cartos.
- Сцена New York открылась: снег и облака с эталонными параметрами, FXMaster 5.0.1 создал два слоя
  эффектов, снег виден на карте после перезапуска сервера.
- Отдельный модуль: `tomcartosmodern-apartment-block` 1.0.5 установлен из приватного архива,
  появился в Add-on Modules, сразу активен (за счёт `core.moduleConfiguration`), компендиум из 10
  сцен работает, фоны 5 сцен мира отдаются с кодом 200.
- Модуль отключён — мир загрузился без ошибок, 66 сцен на месте. Снова включён — активен.
- Модуль удалён через штатное контекстное меню («Uninstall») — каталог модуля исчез, мир после
  перезапуска по-прежнему загружается с 66 сценами.

## Известные ограничения

- Foundry не устанавливает зависимости полностью без участия пользователя: после установки мира
  она открывает окно зависимостей, где нужно нажать «Install selected dependencies automatically».
- Платные наборы Tom Cartos не могут быть установлены из этого репозитория: лицензия автора
  запрещает распространение. Без них 53 сцены открываются без фона, все стены и свет на месте.
- Три mp3 плейлистов и две иконки Monk's Enhanced Journal отсутствуют в исходных данных.
