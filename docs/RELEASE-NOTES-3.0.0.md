# Goldwater cuckold 3.0.0

Мир стал самодостаточным: всё, что нужно для игры, лежит внутри сборки, а ссылок на отсутствующие
файлы не осталось ни одной — это проверяется скриптом по каждому документу мира.

## Сцены

- Было **66** сцен, осталось **12**.
- Удалены **53** сцены на картах Tom Cartos: это платный контент, лицензия запрещает его
  распространение, а без купленного набора фон просто отсутствует. Сцены с данными без картинки
  оставлять нельзя.
- Удалена пустая сцена `void` без фона.
- Вместе со сценами удалены их стены, двери, источники света, тайлы, звуки и заметки.
- Сохранены: `New York`, `New York (old)`, `New York 2`, `Манхатан`, `Манхатан (Copy)`,
  `Title Screen`, `Vegas`, `capella`, `Заброшенный особняк — Подвал / 1 этаж / 2 этаж`.

Осталось 869 стен, 223 двери (из них 91 секретная), 589 источников света, 18 токенов, 62 заметки, 17 тайлов.

Полный список удалённых сцен с причинами — в `audit/v3-scenes.json` и в отчёте к релизу.

## Снег

- `core_snowstorm` удалён со сцен `New York` и `New York 2`.
- Погодный пресет `blizzard` снят с `Манхатан (Copy)`.
- Облака `core_clouds` на обеих сценах New York сохранены, туман на `Title Screen` и `Манхатан`
  тоже.
- Проверка проходит по всем сценам: ни одного эффекта с `snow`/`blizzard` в мире не осталось.

## Токены

- **183** Actor Documents, у **175** заменён основной токен на изображение из библиотеки
  New York by Night.
- **80** персонажей получили альтернативные варианты через Token Variant Art.
- Основной токен выбирается нейтральным: `_noitems` → `_noweapon` → `_plain` → базовый.
- Для случайных NPC (`Random asspull`, `Brute Squad`, `(cuck)old` и прочие неканонические)
  токены подбирались по полу, одежде и роли; повторов почти нет — 85 разных токенов на 86 персонажей.
- У 8 персонажей оставлено прежнее уникальное изображение: в библиотеке нет именно их портрета,
  а подменять персонажа «похожим» нельзя.

Игровые данные не тронуты: изменились только `prototypeToken.texture`, размеры токена и флаг
`flags.token-variants.variants`.

## Модули

- Обязательные: `goldwater-assets` 1.0.0, `fxmaster` 5.0.1, `token-variants` 5.1.6.
- Рекомендуемые: `monks-enhanced-journal` 12.02, `lib-wrapper`.
- Tom Cartos больше не объявляются в `relationships` — они больше не нужны миру.
- Из `core.moduleConfiguration` убраны id наборов Tom Cartos, добавлен `token-variants`.

## Исправлено попутно

- 16 заметок-лестниц ссылались на `icons/svg/stairs.svg`, которого в Foundry нет; заменено на
  `icons/environment/settlement/stone-stairs.webp`.
- Из плейлиста удалены 3 дорожки, файлов которых нет ни в одной папке ассетов
  (`Maenad Veyl — Out of Sight`, `Maenad Veyl — Unhealed`, `Knights & Bishops`).
