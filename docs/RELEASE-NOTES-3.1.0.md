# Goldwater cuckold 3.1.0

Небольшое обновление поверх 3.0.0: у персонажей появился второй облик — их прежний портрет,
а список сцен очищен от пустых папок. Ни сцены, ни токены, ни эффекты, ни игровые данные не менялись.

## Портретные варианты токенов

- В 3.0.0 новый top-down токен получили **175** персонажей. У **150** из них теперь есть ещё один
  вариант — их собственное изображение из мира до обновления (портрет или прежний арт).
- Основной токен остался прежним top-down; портрет добавлен в конец списка
  `flags.token-variants.variants`, поэтому переключаться между ними можно через Token Variant Art.
- Существующие варианты не удалялись и не переставлялись: всего в мире **405** записей вариантов
  (255 из 3.0.0 + 150 новых).
- Портреты не копировались заново: они уже лежат в модуле `goldwater-assets`, откуда их берёт
  поле `img` актора. Новых файлов в архиве мира нет.

### Персонажи без портретного варианта (25)

У этих акторов в мире не было собственного портрета — стояла заглушка Foundry
`icons/svg/mystery-man.svg`, поэтому добавлен только top-down токен:

`hong lu`, `Джерри Смит`, `Валерия Мартинес`, `пидор 1`, `пидор 2`, `Птенец Тзимисце`, `Лобанов`,
`sutener pidor`, `Чижик`, `Вампир`, `Оборотень`, `Эбан Бушар`, `Джон Клэр`, `тяжёлая мама`,
`ганс ланда`, `Мартин Ким`, `Птенец Бруха`, `123`, `Тёмнов`, `So-Sal`, `Птенец Ассамит`,
`Аиша Уайт`, `Птенец Гангрел`, `Вольф`.

Отдельно `Алан Персон`: его исходное изображение в мире — уже top-down токен, портрета нет.

## Пустые папки сцен

Удалено **12** пустых папок: `Car Park`, `Night Club`, `Trainyard`, `City Streets`, `Scarpyard`,
`Apartment Block`, `Sewers`, `Мэдисон Сквер Гарден`, `Subway`, `Office Block`, `Prison`,
`Бернард Колледж`. Остались две папки со сценами — `other` (6 сцен) и `Особняк` (3 сцены),
плюс 3 сцены в корне списка. Все 12 сцен на месте.

## Проверка

- Установка из архива на чистый Foundry 12.331: мир 3.1.0, 12 сцен, 183 актора, 175 с вариантами.
- Все 428 ссылок на файлы отвечают 200, включая 150 новых портретов.
- Token Variant Art 5.1.6 активен: в HUD токена видны и top-down, и портрет; клик по портрету
  меняет изображение токена, `prototypeToken` при этом остаётся прежним top-down.
- В списке сцен пустых папок не осталось.
